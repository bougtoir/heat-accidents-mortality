# Heat and traffic-crash mortality (US & Japan)

Empirical test of whether unusually hot days raise daily **traffic-crash
mortality** — a pathway (heat-impaired driving / undiagnosed heat illness among
crash decedents) that is essentially never coded in crash statistics.

We fit quasi-Poisson **distributed-lag** models on state/prefecture × day panels,
using the **local seasonal temperature anomaly** (deviation from each unit's
day-of-year climatology) so that the estimate reflects *acute unusual heat*
rather than the confounded seasonal driving-exposure envelope. Effects are
decomposed over lag windows (same-day, 1–3 d, 4–10 d) to separate the acute
spike from short-term mortality displacement (harvesting).

## Results (regenerated by the code; see `output/`)

- **United States** (FARS 2016–2022): a +9 °C anomaly raises **same-day** crash
  deaths (RR in `output/us_model_summary.txt`), partly offset by a 1–3 day
  deficit. Robust to national VMT + gasoline controls. Net heat-attributable
  crash deaths per year and comparison with official CDC direct-heat deaths
  (ICD-10 X30) are in `data/processed/us_attributable.csv` and
  `data/processed/cdc_heat_deaths.csv`.
- **Mechanism / vulnerability (US)**: the same-day heat excess is graded by
  road-user exposure (much larger for motorcyclists, pedestrians and cyclists
  than for enclosed vehicle occupants) and concentrated in the hottest hours of
  the day — patterns expected from a heat mechanism, not driving volume. See
  `data/processed/us_subgroup_response.csv` and `us_timeofday_response.csv`.
- **Warming projection (US)**: applying the anomaly exposure-response to a
  uniformly warmer daily climate (+1/+2/+3 °C, activity held constant) projects
  hundreds of additional crash deaths per year per degree
  (`data/processed/us_projection.csv`); a scenario calculation, not a forecast.
- **Japan** (NPA accident open data 2019–2024): same-day effect is in the same
  direction but not statistically significant (far fewer deaths → low power);
  see `output/jp_model_summary.txt`.

All numbers in the manuscript are read from the generated result CSVs; none are
hard-coded.

## Data sources (all public)

| Data | Source |
|------|--------|
| US traffic fatalities | NHTSA FARS `https://static.nhtsa.gov/nhtsa/downloads/FARS/{YEAR}/National/` |
| Temperature (both) | NOAA GHCN-Daily `https://www.ncei.noaa.gov/pub/data/ghcn/daily/` |
| US county centroids / population | Census 2023 Gazetteer + PEP 2019 (needs `CENSUS_API_KEY`) |
| US vehicle-miles travelled | FRED `TRFVOLUSM227NFWA` (FHWA Traffic Volume Trends) |
| US gasoline supplied | EIA `PET.WGFUPUS2.W` (needs `EIA_API_KEY`) |
| US official heat deaths | CDC WONDER Underlying Cause of Death (D76), ICD-10 X30 |
| Japan traffic fatalities | National Police Agency accident open data (`honhyo_YYYY.csv`) |

## Reproduce

```bash
export CENSUS_API_KEY=...   # for US county population
export EIA_API_KEY=...      # for US gasoline (sensitivity only)
make all          # build data, fit US + Japan models, make figures
make manuscript   # build DOCX + editable PPTX (after `make all`)
make test         # light unit tests
```

Raw downloads are cached under `data/raw/`; re-running skips existing files.

## Layout

```
scripts/   build_*.py (data)  analyze_*.py (models)  figures_*.py  model.py  dlnm.py
data/raw/        cached public downloads
data/processed/  analysis-ready panels and result CSVs
output/          model summaries, figures/, manuscript/
tests/           unit tests
```

## Caveats

A state/prefecture-day association between heat and crash deaths does **not**
prove individual-level heat illness in any specific crash; FARS/NPA carry no
post-mortem heat diagnosis. The result is population-level evidence consistent
with an under-recognised acute heat contribution to crash mortality.
