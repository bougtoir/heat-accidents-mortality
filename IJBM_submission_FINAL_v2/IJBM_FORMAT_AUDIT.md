# IJBM Format Audit

Source: Springer "Submission guidelines — International Journal of Biometeorology" (link.springer.com/journal/484/submission-guidelines, checked 2026-09-28).

| Requirement | IJBM rule | Applied |
|---|---|---|
| Article type | Original Research Paper | Yes — cover letter and title page state it |
| Word limit | ≤7,500 words; each figure AND table counts as 250 words | Main text ≈4,300 words + 6 figures + 5 tables (2,750 eq.) ≈ 7,050 — within limit. Secondary display items moved to supplement |
| Abstract | 150–250 words, no undefined abbreviations | 190 words, unstructured; FARS/NPA spelled out |
| Keywords | 4–6 keywords | 6 keywords supplied |
| Title page | Title, authors, affiliations, corresponding author | `IJBM_TITLE_PAGE.docx` |
| Citations | Author–year in text, e.g. "(Hwang 2009; O'Neil and Gillikin 2014)" | Implemented throughout; multi-cites alphabetised |
| Reference list | Springer basic style, alphabetical | Alphabetical list, DOIs included where verified |
| Editable source | .docx accepted | Both inline (review copy) and submission (legends-only) DOCX provided |
| Equations | Editable math | Native OMML display equations for the anomaly and model formulas |
| Declarations | Competing interests + author contributions via submission interface; ethics/funding/data statements in manuscript | "Declarations" section in main doc: ethics, competing interests, funding, contributions, data availability |
| AI use | LLM use documented in Methods/declarations | Documented in Methods and in the Declarations section |
| Data availability | Springer research-data policy statement | Included in Declarations (public sources + full reproducible pipeline link) |
| Highlights | Not required by IJBM | Not produced (documented here) |
| Supplementary material | Permitted as SI | `IJBM_SUPPLEMENT.docx` (Figs. S1–S6, Tables S1–S4) |
| Reporting checklist | STROBE appropriate for observational study | `IJBM_STROBE_CHECKLIST.docx` updated to IJBM section/table numbering |
| Reviewer suggestions | Authors asked to suggest potential reviewers at submission | Flagged in AUTHOR_QUERIES.md — requires author input, not a manuscript file |
| Cover letter | Allowed | `IJBM_COVER_LETTER.docx`, dated 28 September 2026 |

## Residual format notes

- Word count is comfortably within budget; if reviewers request restoring a supplement figure to the main text the budget allows ~1–2 more display items.
- The submission (legends-only) DOCX keeps figure captions with no embedded images for journal production; the inline DOCX is for author review.
